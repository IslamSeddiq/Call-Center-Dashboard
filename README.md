# 🧠 About the Project

This project is an interactive Power BI dashboard designed to help businesses monitor operational performance, understand customer behavior, and evaluate agent and department performance.
The dashboard provides a centralized view of key Call Center KPIs and enables users to move from high-level performance monitoring to detailed operational analysis.

---

# 🎯 Project Objectives

- Monitor overall Call Center performance.
- Track key operational KPIs.
- Analyze call volume over time.
- Evaluate Agent performance.
- Compare Department performance.
- Analyze Average Handling Time (AHT).
- Identify busy days and peak periods.
- Monitor abandoned calls and service levels.
- Turn raw call data into actionable business insights.

# 💡 Business Value

The dashboard helps Call Center managers:

**Monitor → Analyze → Identify → Improve**

Instead of relying on raw tables and static reports, decision-makers can quickly identify performance trends, compare teams and departments, and focus on areas that require improvement.
